# MA Headware

Local visual storefront prototype built with **Vite + plain HTML, CSS and JavaScript**. No UI framework. Kept in its own folder to preserve the existing workspace project.

## Run

    npm install
    npm run dev

## Build

    npm run build
    npm run preview

Includes responsive layout, colour filters, searchable collection, product dialogs, persistent bag, quantity controls, copyable order details and links to order through Instagram. No live checkout, payment processing or inventory backend.

Product photos are displayed as CSS crops of the original images. Logos, embroidery and cap colours have not been redrawn. Colour names and product titles are descriptive website labels. The price is a public Instagram reference; stock, sizing and shipping charges need confirmation before a commercial launch.

Extracted source snapshots: instagram-source.json and more-sources.json. Download provenance: asset-manifest.json. Assets are served locally so the preview does not rely on expiring Instagram image URLs.

Fonts: Barlow Condensed and Manrope from Google Fonts, with local system fallbacks.
